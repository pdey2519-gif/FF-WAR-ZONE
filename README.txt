# FF WAR ZONE

A mobile-friendly top-down battle shooter prototype.

## Play on a computer or phone
Open `index.html` in a modern browser. On mobile, use the left joystick to move and hold FIRE to shoot.

## Build an Android APK with Codemagic
1. Upload this ZIP to a Git repository (GitHub is easiest).
2. In Codemagic, add the repository and select `codemagic.yaml`.
3. Start the `FF WAR ZONE Android APK` workflow.
4. Download `app-debug.apk` from the build artifacts and install it on your Android phone.

This is an original arcade-style prototype, not an official Free Fire product. It currently uses simple 2D graphics and offline gameplay.
